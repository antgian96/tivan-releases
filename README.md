# Tivan — installer Windows

Questo repository contiene soltanto installer e manifest degli aggiornamenti firmati. Il codice del gestionale è privato.

Sito: https://tivan-gestionale.vercel.app

Scarica gli installer dalla sezione Releases. Per aggiornare automaticamente serve la versione 0.8.0 o successiva.

RustDesk è un componente separato, attivato dal cliente nell’app: https://github.com/rustdesk/rustdesk
